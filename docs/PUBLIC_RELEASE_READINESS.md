# جاهزية الإصدار العام

تاريخ الحالة: 2026-06-14

تتبع هذه القائمة الفجوة بين مستودع مصدر جاهز للقراءة العامة وبين إصدار مثبت عام يستطيع المستخدم تثبيته مباشرة.

## المرشح الحالي

- المستودع: `GalaxyRuler/lisan-studio`
- الفرع الافتراضي: `main`
- إصدار المصدر الحالي: `v1.0.0-rc1`
- صفحة الإصدار: <https://github.com/GalaxyRuler/lisan-studio/releases/tag/v1.0.0-rc1>
- ظهور المستودع على GitHub عند آخر تحقق: public
- أصول إصدار `v1.0.0-rc1` عند آخر تحقق: لا توجد أصول MSI منشورة
- self-hosted MSI runner عند آخر تحقق: غير متاح محليا

## بوابة المثبت العام

هذه البوابات يجب أن تمر قبل الادعاء أن المستخدمين يستطيعون تثبيت MSI عام مباشرة من GitHub Release:

| البوابة | الحالة | الدليل / الخطوة التالية |
|---|---|---|
| أصل MSI موجود على صفحة الإصدار | مفتوح | يوجد MSI محلي مبني، لكنه لم يرفق بعد كأصل Release |
| فحص تثبيت MSI مر | محجوب | يحتاج Windows runner معزول أو جهاز QA مصرح به |
| فحص ترقية MSI مر | محجوب | يحتاج Windows runner معزول أو جهاز QA مصرح به |
| قرار التوقيع واضح | مفتوح للإصدار العام | ADR الحالي يسمح ببناء beta/RC غير موقع؛ GA العام يجب أن يعيد تقييم التوقيع |
| ملاحظات الإصدار تذكر حدود المثبت | مفتوح | حدثها عند إرفاق MSI |

## فحوصات الأمان العامة

شغل هذه الفحوصات قبل إرفاق أصول مثبت أو قبل أي push حساس:

```powershell
git status -sb
git ls-files | rg -n '(^|/)\.env|id_rsa|\.pem$|\.pfx$|\.key$|secret|token|credential|private'
rg -n '<private-machine-name>|<absolute-private-path>|<private-runner-name>|<agent-planning-folder>' .
.\scripts\validate.ps1
```

إذا كان متاحا محليا، شغل ماسح أسرار مخصصا مثل Gitleaks أو TruffleHog على الشجرة الحالية وتاريخ Git.

## تغيير الظهور

تغيير ظهور المستودع إجراء يملكه صاحب المستودع. أصبح المستودع عاما، لذلك يجب الحفاظ على القواعد التالية بعد ذلك:

1. لا ترفع أسرارا أو ملفات بيئة أو مواد توقيع.
2. لا ترفع مخرجات `build/` أو `stage/` أو `artifacts/`.
3. لا تدع المستندات العامة وجود MSI منشور أو توقيع أو فحص QA إلا بعد التحقق منه.
4. افصل بوضوح بين "المصدر متاح للعامة" و "المثبت جاهز للتوزيع العام".
